# Прогноз энергопотребления здания — ML-демо

Демонстрационная модель к докладу «Машинное обучение для прогнозирования эксплуатационных характеристик зданий и принятия проектных решений» (Моченцов А.А., гр. АГС-22-2, Санкт-Петербургский горный университет, 2026).

Страница предсказывает нагрузку на отопление и охлаждение здания по его форме, ориентации и остеклению. Модель градиентного бустинга работает прямо в браузере, без сервера.

## Как устроено

- `model/train.py` — обучение модели (Python, scikit-learn) на наборе UCI Energy Efficiency и экспорт деревьев в `model.json`.
- `model.json` — 400 деревьев решений для каждой из двух целевых величин, метрики качества и важность признаков.
- `app.js` — расчёт прогноза в браузере, 3D-модель здания (Three.js), графики.
- `data/energy_efficiency.csv` — исходные данные.

Качество на отложенной выборке (20%):

| Величина | MAE, кВт·ч/м² | R² |
|---|---|---|
| Отопление | 0,28 | 0,999 |
| Охлаждение | 0,64 | 0,989 |

## Запуск локально

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.

Переобучить модель:

```bash
pip install scikit-learn pandas openpyxl
python3 model/train.py ENB2012_data.xlsx
```
